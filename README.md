# 论语-大周礼时代-化身为人-skill

中文 V0.3.1：以《论语》二十篇为主，必要时按需查阅本地《礼记》四十九篇；引用原典、讲清意思并给具体回应。劝诫时也可用核实的典籍故事，或明确标注的创作寓言，借古喻今。

完整收录所选《论语》底本二十篇、512 章；新增《礼记》所选底本古文，按通行四十九篇组织、2979个本地定位段落。原先八个主题卡保留为详解示范，适用不限于它们：家庭、亲密关系、工作、金钱、情绪、挫折、选择、合作、时间、哀伤、礼仪与日常相处都可从全书寻找启发。经典增加理解问题的角度，助手仍需结合事实、现代知识与个人意愿；完整收录不意味着每个问题都有经典答案，也不承诺解决所有生活问题。

## 回答方式

通常按“原文与出处 → 白话理由 → 具体回应”。例如面对“想去外地工作，父母说我不孝”：

“父母在，不远游，游必有方。”——《论语·里仁》4.19

古文先提出不轻易远行的限制，又要求出行有明确去处。用于今天，可以重视照护和联系，同时结合现代条件保留成年人的工作选择，不能把现代调整说成古文本来就没有限制。

先问父母最担心的是照护、联系还是经济，再提出你能做到的安排，同时评估这份工作对你的意义。

“别讲大道理”“给一个下一步”仍保留短原文、一句解释和一个动作。明确不引用、不解释、只要一句具体表达或只想被倾听时，尊重用户需要。纯计算、代码执行与一般事实查询按原任务处理；紧急帮助优先。已知出处核查先列所查原文；未知句子查本地全文，只报告实际范围，未命中不等于所有版本、改写或其他文献都不存在。

## 使用

本目录就是完整技能包。保留整个 `lunyu-become-human` 目录及相对路径，明确请求：“读取 SKILL.md，使用论语-大周礼时代-化身为人-skill 帮我分析这件事。”
在 Codex 中可复制到自己配置的技能目录，重新打开会话后使用 `$lunyu-become-human`；实际发现目录以运行环境为准。本次更新项目包，没有修改全局配置。

正文按篇拆分，每次只读相关一两章；全文存本地不等于每轮全部加载。基础使用没有网络或额外库依赖，可选查询只需 Python 3.9+ 标准库：

```text
python scripts/lookup.py --id 14.34
python scripts/lookup.py --keyword 以直报怨
python scripts/lookup.py --chapter 尧曰 --limit 0
python scripts/lookup.py --book liji --chapter 学记
python scripts/lookup.py --book liji --keyword 禮尚往來
python scripts/lookup.py --book liji --id LJ-018-004
```

省略 `--book` 保持原有《论语》查询；`--book liji` 或 `--book 礼记` 查询《礼记》。关键词搜索忽略标点和空白，不做语义或简繁转换，默认最多五条；《礼记》保留繁体原字，未命中需考虑原字、改写和简繁差异。篇名支持索引中的简体名或底本繁体名。没有 Python 可从 [原典索引](references/analects.md) 打开相应 Markdown。

可以试：“工作太憋屈，想今晚裸辞”“多赚钱是不是就不够君子”“受了伤一定要原谅吗”“亲人去世，不想办昂贵仪式”“同龄人都升职买房，我是不是落后了”。

《礼记》按需使用：礼仪与回礼、教学、家庭照护、哀伤和仪式等问题需要补充解释，或用户明确问这本书时，先读 [辅助典源说明](references/liji.md)，再查相关段及上下文；不要求每轮查两书。引用写成 `“原文”——《礼记·篇名》`，`LJ-` 编号只是本地定位号，不是通行章号。古代礼制须结合历史语境解释，不直接转成今天的义务。

## 测试与来源

执行 `python tests/check.py` 和 `python tests/check_liji.py`。前者检查二十篇512章完整性、逐篇正文与JSON一致性、哈希、旧十一章快照、本地查询、链接和31条合成样例的明确引用约束。新增《礼记》检查验证49篇覆盖、2979段的定位与表示一致性、哈希、CLI与错误引用拒绝，以及8条合成样例的明确引用/例外约束。脚本不能验证释义、同理心或实际模型行为。
此前 [DSH 实测](tests/dsh-review.md) 与 [Codex 实测](tests/codex-review.md) 原样保存，均是旧轮次记录。另保存此前DSH十条与Codex五条 [生活实测审读](tests/life-review.md)：首句/例外格式均通过，DSH仍有释义过满、确定性过高和简短请求扩写的问题；Codex提供的五条定性达标。V0.2.1据此修清解释边界，这31条用例的新版实时评测仍待执行，合成样例不等于实测通过。

《论语》古文依据 MIT 授权电子底本整理，保留 [第三方许可原件](references/第三方许可.txt)。分章以本底本为准，其他版本可能不同。新增解释与案例为本项目原创，没有复制受版权保护的现代译文或注释。
独立古文 PDF 经简繁与标点归一化后，445章整章匹配，67章有文字差异、漏句或抽取问题；记录两处明确校正，其余保留底本并标出待核。这不是学术校勘定本。CTEXT 抓取受限，运行不依赖它。

《礼记》正文来源于固定提交的 [汉籍リポジトリ KR1d0052](https://github.com/kanripo/KR1d0052/tree/17289bc016009d28fbe51f98afd87d510da2b0ec)。仅整理公版古文，不收入来源注释或现代译注；不套用《论语》来源的 MIT 许可。底本50个文件中的《丧大记》两部分合并展示，不改原字；全文未作独立校勘，发现重复引号等录入疑点仍保留并说明。

两书保留古代礼制、君臣、性别、阶层和丧制内容，可以理解、讨论与质疑，不把它们直接转换成现代义务、群体判断或专业结论。

## 发布与安装

V0.3.1 的机器标识仍为 `lunyu-become-human`。下载对应 Git 标签的源码包，解压后将整个技能包目录命名为 `lunyu-become-human`，放入自己配置的技能目录；保留 `scripts` 与 `references` 相对路径，重新打开会话后使用 `$lunyu-become-human`。仅复制 `SKILL.md` 会缺少离线典源。

此版本验证本地语料、检索和合成样例，不宣称已完成真实模型或人工语义评测；目标助手是否自动发现技能取决于其技能目录配置。
