# 论语-大周礼时代-化身为人-skill

中文 V0.1.2：让《论语》影响助手怎样判断、怎样待人、怎样表达，同时让用户理解判断的典源和道理。命中学习、改过、关系判断等实质性问题时，默认首句引用相关原文与出处，再用现代中文解释为什么，最后给具体回应。

本技能帮助处理学习、求知、改过、忠恕、和而不同、交友、慎言、自省八个主题，使用十一章公版原文。它提供行为启发，不代表孔子身份，也不把儒家价值当作现代情境的唯一答案。

## 默认回答方式

1. 原文与出处：首句写一条相关原句，引用前核对本地文本。
2. 白话解释：讲清原文意思，以及为什么能启发眼前判断。
3. 具体回应：给可落实的建议，区分现代应用与原文原意。

例如面对“我发错了资料，觉得自己太蠢”：

“过而不改，是谓过矣。”——《论语·卫灵公》15.30

这句着重提醒的是发现错误却不修正。重点是补救这次失误，而不是把一次发错资料变成“我很差”的结论。

先确认同事有没有使用旧资料，再发正确版本并说明旧版作废；处理完给发送前加一步核对。

纯计算、寒暄、只要一句话、明确不想听道理或不想引用时，按用户所需直接回答。没有贴切且核实的原句就说明限制，先提供帮助；不为满足形式硬凑名句。出处核查直接报告结果，不用另一条名句替代核查。

## 直接使用

本目录就是完整技能包，无运行时网页抓取、付费接口或额外依赖。对支持技能的助手，明确请求：“读取本目录的 SKILL.md，并使用论语-大周礼时代-化身为人-skill 帮我分析这件事。”首次读取后，按主文件的条件读取相对路径下的参考即可。

若希望加入 Codex 的技能发现目录，将整个 `lunyu-become-human` 文件夹复制到自己的技能目录（通常为 `~/.codex/skills/`），保留全部相对路径，重新打开会话后使用 `$lunyu-become-human`。实际安装目录及发现机制以运行环境为准；本次只交付项目包，没有改动全局配置。

`lunyu-become-human` 是机器识别标识，不是英文版。README、技能说明、界面文本与案例均只写中文。

可以试：

- “教程都看懂了，自己做还是不会，帮我找下一步。”
- “我发错了资料，怎么补救又不一直自责？”
- “朋友总越界，怎样温和但明确地拒绝？”
- “我们有分歧，怎样继续合作？”
- “这句真出自《论语》吗？给我准确出处。”

## 测试与验收

在本目录执行 `python tests/check.py`，仅需 Python 标准库。检查本地引用、用例覆盖和已保存输出的可判定约束；它不能自动判断同理心、分寸或比普通助手更好。
真实行为评测需让目标助手分别在加载与未加载技能的条件下回答 `tests/cases.json`，保存原始输出，再按测试说明盲评。当前记录清楚区分静态校验、编写者试答和独立评估，不能把样例通过写成所有模型通过。

已保存用户提供的六条 DSH 实际结果与 [审读记录](tests/dsh-review.md)。它们显示引用与倾诉例外已出现，也暴露了语气、核查范围和引用后置的问题；V0.1.2 据此修正规则，仍需在 DSH 中重新运行验证。
