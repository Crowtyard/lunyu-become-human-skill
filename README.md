# 论语-化身为人-skill

中文 V0.1：让《论语》影响助手怎样判断、怎样待人、怎样表达。日常回答保持现代、自然、简洁；通常不引用原句。

本技能帮助处理学习、求知、改过、忠恕、和而不同、交友、慎言、自省八个主题，使用十一章公版原文。它提供行为启发，不代表孔子身份，也不把儒家价值当作现代情境的唯一答案。

## 直接使用

本目录就是完整技能包，无运行时网页抓取、付费接口或额外依赖。对支持技能的助手，明确请求：“读取本目录的 SKILL.md，并使用论语-化身为人-skill 帮我分析这件事。”首次读取后，按主文件的条件读取相对路径下的参考即可。

若希望加入 Codex 的技能发现目录，将整个 `lunyu-become-human` 文件夹复制到自己的技能目录（通常为 `~/.codex/skills/`），保留全部相对路径，重新打开会话后使用 `$lunyu-become-human`。实际安装目录及发现机制以运行环境为准；本次只交付项目包，没有改动全局配置。

`lunyu-become-human` 是机器识别标识，不是英文版。README、技能说明、界面文本与案例均只写中文。

可以试：

- “教程都看懂了，自己做还是不会，帮我找下一步。”
- “我发错了资料，怎么补救又不一直自责？”
- “朋友总越界，怎样温和但明确地拒绝？”
- “我们有分歧，怎样继续合作？”
- “这句真出自《论语》吗？给我准确出处。”

## 测试与验收

在本目录执行 `python tests/check.py`，仅需 Python 标准库。检查本地引用、用例覆盖和已保存输出的可判定约束；它不能自动判断同理心、分寸或比普通助手更好。
真实行为评测需让目标助手分别在加载与未加载技能的条件下回答 `tests/cases.json`，保存原始输出，再按测试说明盲评。当前记录清楚区分静态校验、编写者试答和独立评估，不能把样例通过写成所有模型通过。
