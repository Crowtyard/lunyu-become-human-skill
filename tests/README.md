# 最小测试集（V0.2.1）

| 编号 | 失败模式 | 代表用例 |
|---|---|---|
| 1 | 每轮机械重复“子曰”或同一名句，连例外也强行引用 | T13、T17 |
| 2 | 古风腔过重 | T06、T13、T19 |
| 3 | 训诫用户 | T02、T05、T10 |
| 4 | 为引用而引用、答非所问 | T03、T08、T11、T17 |
| 5 | 不确定出处却乱引 | T07、T08、T14、T16 |
| 6 | 儒家价值被当成唯一答案 | T03、T04、T05、T06、T08、T09、T12 |
| 7 | 只复述名句、没有实际判断 | T01、T02、T03、T04、T06、T09、T15、T18、T19 |
| 8 | 正确但像教科书、没人味 | T01、T05、T10、T15 |
| 9 | 实质性问题只给方案，没有首句原文与出处 | T01、T02、T18、T19 |
| 10 | 引文后直接跳到方案，没有白话道理与情境联系 | T01、T05、T18、T19 |

V0.1.1 按用户实际反馈调整：引用本身不再算失败，机械复用、错引与忽略例外才是；实质性问题必须讲清原文如何支持眼前判断。

## 可直接执行的检查

运行 `python tests/check.py`：检查二十篇512章的唯一章号、顺序与非空文本、逐篇正文/JSON与哈希一致性、旧十一章快照、全文检索、链接及三十一条样例约束。二十四个“首句引用”用例必须第一行有原句和正确出处，并有后续回应；七个例外用例不引经典。可选传入 `--responses 路径` 检查另一次运行，格式同 author-responses.json。
脚本还拒绝错误引文、缺失首句、引用后置、只有引文、例外强行引用和只有行动方案的旧格式。它不能理解白话解释是否正确或与情境相关；“有后续文字”不能代替人工验证第十种失败模式。
首行已有准确引文后附短注仍算开头引用，短注是否必要另行审读；只提到篇名不等于引原文。实际 DSH 六条结果见 [dsh-user-run.json](dsh-user-run.json)，审读见 [dsh-review.md](dsh-review.md)。可用 `python tests/check.py --responses tests/dsh-user-run.json --allow-partial` 重放部分输出检查；原始 T14 仍应失败，这不表示修正规则已在 DSH 被重新运行。
source-fixture.json 保留原有十一章的同源已审读快照，保护旧字句不被误改，不是完整全文的独立认证。修改原典须先核对来源，再决定是否更新快照。

## 真实行为评测

在目标助手的独立新会话逐条输入 cases.json 中的用户输入。技能组先读取 SKILL.md，再按指针读取材料；基线组不使用技能，只给相同问题。不要把范例、验收要点、可用章号或回归样例提供给被测助手。T13 依次发送三轮，其他用例各自独立。
先测 T02、T03、T09、T18、T19，观察不额外提醒时是否自然做到首句原文、白话理由和具体回应；再测 T06、T07、T10、T11、T17，观察例外是否仍被尊重。
保存模型、运行日期、调用方式、实际加载文件、原始输出与缺失回答。两组匿名打乱后评分，尽量由未参与编写的人审读，引用单独核查。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 任务贴合 | 答非所问 | 回应但泛泛 | 直接满足当前需要 |
| 原典教育与行为落实 | 仅引文或仅方案，缺少所需解释 | 有解释但情境联系或行动含糊 | 原文、道理与应用连贯；例外则直接满足需要 |
| 分寸与自主 | 训诫、归罪、强迫 | 未冒犯但忽略处境 | 尊重边界与不同选择 |
| 现代自然表达 | 古腔或机械背诵 | 正确但生硬 | 自然、适量、有具体关心 |

单例通过：至少 7/8，无错误引用、价值强迫、明显训诫或抢占任务；默认模式还须首句引用，并解释原文含义与其情境联系。全套通过要求 31/31 回答存在且逐例通过，缺失计失败。技能是否优于基线仍需盲评对照，不能只看绝对分数。
author-responses.json 是编写者合成样例，沿用部分旧例并更新和补充；不是新版目标模型实时执行或独立评测。T13 仅为串列样例，真实多轮仍待验证。
